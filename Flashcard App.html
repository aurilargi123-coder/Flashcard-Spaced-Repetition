⚙️ Panduan & Integrasi Supabase

Setup database PostgreSQL, Row Level Security (RLS), dan PostgreSQL RPC Function.

⚡ Hubungkan Proyek Supabase Anda

Mode Demo (Offline)

Masukkan Project URL dan Anon Public Key dari dashboard Supabase Anda. Kredensial disimpan di LocalStorage peramban secara aman.

📋 Langkah 1: Buat Proyek di Supabase

  1. Buka supabase.com dan buat proyek baru (contoh: flashmind-uts).
  2. Buka menu Authentication → Providers, pastikan provider Email aktif. Untuk kemudahan pengujian UTS, nonaktifkan opsi "Confirm Email" agar pengguna bisa langsung masuk tanpa verifikasi link email.

🗄️ Langkah 2: Jalankan SQL Schema & PostgreSQL RPC Function

Buka menu SQL Editor di dashboard Supabase Anda, lalu tempel (paste) dan jalankan (Run) seluruh script SQL berikut:

-- ========================================================= -- FlashMind Database Schema & PostgreSQL RPC Function -- Aplikasi Flashcard & Spaced Repetition untuk UTS Mahasiswa -- ========================================================= -- 1. Enable UUID Extension CREATE EXTENSION IF NOT EXISTS "uuid-ossp"; -- 2. Tabel Dek Belajar (Decks) CREATE TABLE IF NOT EXISTS decks ( id UUID DEFAULT uuid_generate_v4() PRIMARY KEY, user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE, title TEXT NOT NULL, description TEXT, color TEXT DEFAULT '#6366f1', created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW() ); -- 3. Tabel Kartu Flashcard (Cards) CREATE TABLE IF NOT EXISTS cards ( id UUID DEFAULT uuid_generate_v4() PRIMARY KEY, deck_id UUID REFERENCES decks(id) ON DELETE CASCADE, front TEXT NOT NULL, back TEXT NOT NULL, ease_factor FLOAT DEFAULT 2.5, interval INTEGER DEFAULT 0, repetitions INTEGER DEFAULT 0, next_review TIMESTAMPTZ DEFAULT NOW(), created_at TIMESTAMPTZ DEFAULT NOW() ); -- 4. Tabel Riwayat Review (Review History untuk Statistik Retensi) CREATE TABLE IF NOT EXISTS review_history ( id UUID DEFAULT uuid_generate_v4() PRIMARY KEY, card_id UUID REFERENCES cards(id) ON DELETE CASCADE, user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE, quality INTEGER NOT NULL CHECK (quality >= 0 AND quality <= 5), reviewed_at TIMESTAMPTZ DEFAULT NOW() ); -- 5. Aktifkan Row Level Security (RLS) ALTER TABLE decks ENABLE ROW LEVEL SECURITY; ALTER TABLE cards ENABLE ROW LEVEL SECURITY; ALTER TABLE review_history ENABLE ROW LEVEL SECURITY; -- 6. Kebijakan RLS (Security Policies) CREATE POLICY "Users can CRUD own decks" ON decks FOR ALL USING (auth.uid() = user_id); CREATE POLICY "Users can CRUD cards in own decks" ON cards FOR ALL USING (deck_id IN (SELECT id FROM decks WHERE user_id = auth.uid())); CREATE POLICY "Users can CRUD own reviews" ON review_history FOR ALL USING (auth.uid() = user_id); -- 7. PostgreSQL Function / RPC: Algoritma Spaced Repetition SM-2 CREATE OR REPLACE FUNCTION calculate_next_review( p_card_id UUID, p_quality INTEGER ) RETURNS JSON AS $$ DECLARE v_card cards%ROWTYPE; v_ease FLOAT; v_interval INTEGER; v_reps INTEGER; BEGIN SELECT * INTO v_card FROM cards WHERE id = p_card_id; v_ease := v_card.ease_factor; v_interval := v_card.interval; v_reps := v_card.repetitions; -- Algoritma SuperMemo 2 (SM-2) IF p_quality >= 3 THEN IF v_reps = 0 THEN v_interval := 1; ELSIF v_reps = 1 THEN v_interval := 6; ELSE v_interval := ROUND(v_interval * v_ease); END IF; v_reps := v_reps + 1; ELSE v_reps := 0; v_interval := 1; END IF; -- Penyesuaian Ease Factor v_ease := v_ease + (0.1 - (5 - p_quality) * (0.08 + (5 - p_quality) * 0.02)); IF v_ease < 1.3 THEN v_ease := 1.3; END IF; -- Perbarui status kartu di database UPDATE cards SET ease_factor = v_ease, interval = v_interval, repetitions = v_reps, next_review = NOW() + (v_interval || ' days')::INTERVAL WHERE id = p_card_id; -- Catat riwayat review untuk statistik retensi INSERT INTO review_history (card_id, user_id, quality) VALUES (p_card_id, (SELECT user_id FROM decks WHERE id = v_card.deck_id), p_quality); RETURN json_build_object( 'ease_factor', v_ease, 'interval', v_interval, 'repetitions', v_reps, 'next_review', NOW() + (v_interval || ' days')::INTERVAL ); END; $$ LANGUAGE plpgsql SECURITY DEFINER;

📖 Prinsip Kerja Algoritma SM-2 & Fitur PostgreSQL RPC

Aplikasi ini memanfaatkan fitur PostgreSQL RPC (Remote Procedure Call) pada Supabase untuk memindahkan seluruh perhitungan interval memori ke server database (database-side logic). Hal ini memastikan konsistensi data, atomisitas transaksi antara kartu dan riwayat review, serta proteksi keamanan melalui SECURITY DEFINER.

  • Lagi (Quality 1): Tidak ingat. Repetisi di-reset ke 0, interval kembali ke 1 hari.
  • Sulit (Quality 3): Ingat dengan susah payah. Repetisi bertambah, Ease Factor sedikit menurun.
  • Baik (Quality 4): Ingat dengan wajar. Interval bertambah sesuai Ease Factor.
  • Mudah (Quality 5): Sangat mudah diingat. Ease Factor bertambah sehingga interval berkembang lebih cepat.
